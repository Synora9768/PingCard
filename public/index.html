使用说明

iOS / iPadOS 需要先「添加到主屏幕」

Safari 自 iOS 16.4 起支持 Web Push，但只有把本站添加到主屏幕并以 PWA 方式打开后才可用。 操作：分享按钮 → 添加到主屏幕 → 从主屏幕图标打开本页 → 点击「开启通知」。

调用推送接口（curl 示例） 
curl -X POST https://your-domain/api/notify \
  -H "Authorization: Bearer $NOTIFY_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "userId": "'"$(echo $USER_ID)"'",
    "templateId": "t_demo",
    "variables": { "title": "服务器告警", "body": "CPU 使用率超过 90%" }
  }'
